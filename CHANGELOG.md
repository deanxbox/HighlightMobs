# Changelog

## 1.0.4

- Added per-variant highlighting: clicking a mob with variants (wolves, cats, frogs, horses and more) opens a variant screen with an option to select all or none. Choices are saved.
- Added flat 2D face icons for every mob and variant, drawn from bundled textures so resource packs no longer change them. Non-mob entries use their item textures.
- Icons now load without joining a world.
- Fixed long labels overlapping icons and selection controls.
- Single jar covering Minecraft 26.1, 26.1.1 and 26.1.2.

## 1.0.3

- Added quick-select buttons: Select All Passive, Select All Neutral/Hostile, Select All Non-Mobs and Select All Mobs. Each replaces the current selection.

## 1.0.1

- Initial release for Minecraft 26.1.2.
